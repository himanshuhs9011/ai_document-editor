What you get

A familiar editor
Styles, lists, find and replace, autosave. Opens Word, PDF and text; saves as Word.
An assistant that suggests, not overwrites
Edits come back as changes you accept or reject, paragraph by paragraph.
AI where you type
Type / to continue, fix grammar, shorten, translate or make a table.
Studio: a writing team
Specialist agents plan, draft and review whole documents: legal, reports, research, scripts, courses and more.
Deep read for long documents
The AI reads the whole text for summaries, “list every deadline” questions and comparisons.
Private by default
Works offline. Text goes only to the AI provider you choose, and only when you use AI.

Install in four steps

  1. 1

    Download the installer

    Get AI-Document-Editor-Setup-1.0.0.exe from the latest release on GitHub.

  2. 2

    Run it

    If Windows shows “Windows protected your PC”, click More info, then Run anyway. The app isn’t code-signed yet.

  3. 3

    Create your account

    Open AI Document Editor from the desktop or Start menu and click Create an account. It’s made on this PC; no internet needed.

  4. 4

    Add an AI key

    Click Add AI key at the top, choose a provider and paste your key. Google Gemini has a free key; OpenAI, Claude, Groq and others work too.

Where your work lives

  • Everything, accounts, documents, chats and saved keys, is in %APPDATA%\AI Document Editor. Paste that into the File Explorer address bar to open it.
  • To back up, close the app and copy that folder.
  • Uninstall from Windows Settings, Apps. Your folder is kept until you delete it.
  • API keys are stored encrypted, protected by Windows for your user account.

Questions

Is it free?

Yes, and open source. AI usage is billed by your provider; Gemini’s free tier costs nothing.

Does it need the internet?

Only for AI. Writing, opening files, saving and exporting all work offline.

AI says “quota exceeded”. What now?

Free keys allow a few requests a minute. Wait a minute and try again.

Can I use it on another PC with the same account?

Accounts belong to the PC they were made on. Copy your data folder to move your documents.

Is there a Mac or Linux version?

Not yet as an installer. The source code runs anywhere Python and Node.js do.

Can it read scanned PDFs?

Not yet in the Windows app: scanned pages import without text. PDFs with real text work.
