01 // the problem

Why an AI document editor

Most AI writing still happens in a chat window, away from the document. The AI never sees the whole file, never knows your other files, and every answer is all-or-nothing.

the chatbot way
  1. ✕Copy text out of your document
  2. ✕Paste it into a chatbot
  3. ✕Copy the answer back
  4. ✕Fix the formatting it broke
  5. ✕Repeat for every change
this editor
  1. ✓Ask right where you write
  2. ✓The AI sees the whole document
  3. ✓Changes are marked word by word
  4. ✓Accept or reject each one
  5. ✓Formatting kept; one undo puts it back
◉

It sees your document

Its structure and formatting too, so “make the budget section formal” just works.

✎

You stay the editor

AI edits arrive as suggestions. Nothing changes until you accept it.

⌂

Your files stay yours

Documents and accounts live on your PC. Text goes only to the AI provider you pick.

How to use it

  1. Click the chat options under the message box (This document · Quick) and choose Write a whole document.

  2. Pick a profession on the left and a document type, and answer the brief.

  3. Optionally tick source files: facts from them are cited as [1], [2].

  4. Choose Draft, or Draft, review and revise for the reviewers’ pass.

  5. Click Write it and watch each agent work, section by section.

  6. When it’s done, Add to my document. If the document isn’t empty, it arrives as a review.

05 // deep read · rlm · recursive language model

Reads the whole document. With code.

Normal chat only sees what fits in one prompt. Deep read puts the whole text in a sandbox as a variable; the model writes small programs to search, slice and chunk it, hands pieces to helper model calls and combines the answers.

normal chat

sees the part that fits in one prompt

deep read

reads every chunk, then combines

  1. 01The text becomes a variableThe whole document goes into a sandbox as context, not into the prompt.
  2. 02The model writes codeSmall programs that search, slice and split it into chunks.
  3. 03Helpers read the piecesEach chunk goes to a helper model call.
  4. 04It combines the answersUnder about 24,000 characters it just reads in one pass.
step 1 · sandbox python 
# the model writes this; the sandbox runs it
parts = chunks(context, 20000)
answers = llm_query_batch(["List every deadline:\n" + p for p in parts])
print(len(parts), answers)
# next step: combine the answers and finish

Locked sandbox: no files, no network, no imports, with time and size limits.

How to use it

  1. Open the long document.

  2. Click the chat options (This document · Quick) and pick Deep read under Reading mode.

  3. Ask your question. A line shows each step as it reads.

  4. Under the answer, Read with code folds out the exact code it ran and what it printed.

AI requests

Short texts
1 read in one pass
Long texts
≤ 8 + 24 up to 8 steps and 24 helper reads

07 // everyday ai

The other AI features

Chat and review

The assistant reads your open document. Questions are answered in the chat; requests to change the document come back as suggested changes you review before anything is applied.

  1. Type in the message box at the bottom of the assistant and press Enter.
  2. For an edit, a review panel opens above the document with each change marked word by word.
  3. Accept or reject each change, or click Accept all. One undo (Ctrl+Z) reverts the whole edit.
  4. Select any text for quick actions too: Improve Grammar, Make Concise, Add Detail, Formal or Friendly Tone, Summarize.

Autocomplete

As you pause, the AI suggests how your sentence continues, in grey. Press Tab to take it, or keep typing to ignore it.

  1. Open More tools (⋯) in the toolbar and turn on AI autocomplete.
  2. Write, and pause at the end of a sentence. Press Tab to accept the suggestion.
  3. Each suggestion is a request, so a free key’s per-minute limit runs out faster.

11 // faq

Questions

01Is it free?

Yes, and open source. AI usage is billed by your provider on your own key; Gemini’s free tier costs nothing.

02The AI says “quota exceeded”.

Free keys allow a few requests a minute. Wait a minute; Studio and Deep read make several requests each, so heavy use suits a paid key.

03Can I use my account on another PC?

Accounts belong to the PC they were made on. Copy the data folder to move your documents.

04Mac or Linux?

Not yet as an installer. The source code runs anywhere Python and Node.js do.

05Scanned PDFs?

Not yet: there’s no OCR in the Windows app, so scanned pages import without text. PDFs with real text work.
