AI Document Editor - Portable Version
=====================================

How to Run:
-----------
1. Double-click 'start-portable.bat'.
2. Wait for the initialization to complete.
   - The first run might take a few minutes to set up the virtual environment and download necessary models.
   - Ensure you have an internet connection for the first run if models need to be downloaded.
3. The application will open in your browser.

Troubleshooting:
----------------
- If the app fails to start, check the terminal window for error messages.
- If you see "Failed to fetch" in the browser, it means the backend server hasn't started yet. Wait a moment and refresh.
- Ensure you have Python 3.8 or higher installed.
- Ensure Ollama is running (run 'install-ollama.bat' if needed).

Data Storage:
-------------
- All your documents and sessions are stored in the 'backend/data' folder.
- This folder is created fresh on the first run.
